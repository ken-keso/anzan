# あんざんチャレンジ（サンプル実装）

`暗算アプリ仕様.md` に基づいたサンプルです。HTML/CSS/JS のみで完結する
PWA として実装しています。

## ファイル構成

```
anzan-app/
├── index.html    … 画面のHTML構造のみ
├── style.css     … スタイル（メンテナンス用に分離）
├── app.js        … 画面遷移・出題・判定などのロジック（メンテナンス用に分離）
├── config.js     … モードごとの問題数などの設定（外部ファイルで変更可能）
├── manifest.json … PWAマニフェスト（ホームアイコン化・standalone表示用）
├── sw.js         … Service Worker（オフラインキャッシュ）
├── icon.svg      … アプリアイコン
├── users.json    … 初期ユーザ名の参照ファイル
└── README.md
```

## 試し方

### そのまま試す（一番早い）
`index.html` をAndroidスマホのChromeで直接開くだけで動作します
（ダブルタップで開くか、PCで開いてChrome DevToolsのスマホ表示で確認）。
`config.js` は `<script>` タグで読み込む方式なので、`file://` で直接
開いた場合でも設定が反映されます（詳細は下記「問題数の設定」参照）。
PWA登録（マニフェスト・Service Worker）は `file://` では自動的に
スキップされますが、アプリ自体の動作には影響しません。

### PWAとしてインストールして試す
GitHub Pages や Netlify、あるいは社内サーバーなど **https（またはlocalhost）**
でこのフォルダをそのまま配信してください。Android Chromeで開くと
「ホーム画面に追加」からアイコン化・全画面起動ができます。

```bash
# 手元で簡易確認する場合の例
npx serve anzan-app
```

## 仕様との対応・実装メモ

- **画面遷移**: トップ→ユーザ選択→モード選択→計算→結果 を、
  1つの `index.html` 内で `<section class="screen">` の表示切替により実現。
  モード選択画面からは「けっかをみる」で過去の記録一覧にも遷移できます。
- **ユーザは3人固定 / 外部ファイルで名前管理**:
  ブラウザのサンドボックス制約上、Webアプリから直接ローカルファイルへ
  書き込むことはできないため、`localStorage` を実体として使い、
  ユーザ選択画面右上の⚙から名前変更・**JSON書き出し/読み込み**が
  できるようにしています。書き出した `users.json` を編集して読み込み直す
  ことで、実質的に外部ファイルでの管理が可能です。
  （Capacitor等でネイティブAndroidアプリ化する場合は、この部分を
  ファイルシステムAPIに差し替えるだけで本来の仕様どおりになります）
- **モード4種 × 難易度3種**: `add/sub/mul/div` それぞれに
  かんたん・ふつう・むずかしいの数値レンジを設定（`app.js` 内
  `genAdd/genSub/genMul/genDiv` 参照）。

  | モード | かんたん | ふつう | むずかしい |
  |---|---|---|---|
  | たしざん | 1桁+1桁 | 1桁+2桁 | 2桁+2桁 |
  | ひきざん | 1桁-1桁 | 2桁-1桁 | 2桁-2桁 |
  | かけざん | 九九（1桁×1桁） | 2桁×1桁 | 2桁×2桁 |
  | わりざん | 九九を使った割り算 | 2桁÷1桁 | 2桁÷2桁 |

  割り算は必ず割り切れる組み合わせ（被除数・除数とも指定の桁数に収まる範囲）
  を生成します。
- **バラ九九モード（新規）**: `mul`（かけざん）とは別に、なんいど選択なしの
  1種類だけのモード `bara` を追加。1〜9×1〜9の掛け算 **全81パターンを
  必ず1回ずつ**、出題順だけシャッフルして出題します（`app.js` の
  `generateBaraSet()`）。なんいどが1つしかないモードを選ぶと、モード選択
  画面の「なんいど」欄は自動的に非表示になり、そのまま「スタート」が
  押せるようになります（`applyDifficultyUiForMode()`）。記録・スタンプの
  ルールは他モードと共通です。
- **スタンプ獲得条件の変更**: 従来の「まんてん（全問正解）」から、
  **「問題数の半分以上正解」**でスタンプが1つ加算されるように変更
  （`finishSession()` 内 `earnsStamp`）。満点のときは演出テキストが
  「まんてん！」、半分以上〜満点未満のときは「はんぶんいじょう
  せいかい！」に変わります。
- **スタンプのリセット機能**: 「けっかをみる」画面のスタンプ表示部分に
  🗑リセットボタンを追加。確認ダイアログのあと、そのユーザーの
  スタンプ数を0に戻せます（`App.resetStamps()`）。
- **問題数はモードごとに外部ファイルで変更可能**: `config.js` の
  `questionsPerMode` にモードごとの問題数を設定します。

  ```js
  window.APP_CONFIG = {
    questionsPerMode: {
      add: 20,
      sub: 15,
      mul: 10,
      div: 10
    }
  };
  ```

  ファイルを書き換えて保存するだけで、次にアプリを開いたときに
  反映されます（モード選択画面の各カードにも「◯もん」と表示）。

  **なぜ `.json` ではなく `.js` なのか**：当初は `config.json` を
  `fetch()` で読み込む方式でしたが、`file://` で直接開くと `fetch` が
  ブラウザのセキュリティ制約（CORS）でブロックされてしまい、
  ファイルを書き換えても反映されない問題がありました。`config.js`を
  `<script src="config.js">` として読み込む方式に変更したことで、
  `file://` でもホスティングでも確実に反映されるようになっています。
  （ホスティングして使う場合に備え、`sw.js` 側も `config.js` を
  ネットワーク優先で扱うようにしてあるので、Service Worker による
  キャッシュの影響も受けません）
- **計算画面**: 画面下部に電卓風テンキー＋確定ボタン。経過時間は
  0.25秒ごとに更新表示。確定後は〇×とマスコットの表情、
  Web Audio APIによる効果音（音声ファイル不要）でフィードバックし、
  不正解時のみ正解を表示してから次の問題へ自動遷移します。
- **結果画面**: 出題数分の一覧（式・回答・正誤・不正解時は正解も表示）、
  正答数・タイム・正答率のサマリーを表示し、約4秒のファンファーレを
  再生します。
- **結果の保存件数**: セッション結果は `localStorage`
  （`anzan_results_<userId>`）に **モード×難易度の組み合わせごとに
  最大20件**保存されます。21件目を保存する際は、そのモード・難易度の
  中でいちばん古い記録から自動的に削除されます（他のモード・難易度の
  記録には影響しません）。
- **過去の結果画面**: モード選択画面の「📊 けっかをみる」から、
  4モード×3難易度＝12区分ごとに、日時・正答数・タイムの一覧を
  新しい順で確認できます（`app.js` の `renderHistory()`）。
